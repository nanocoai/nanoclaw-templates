# manager

Role: people manager or team lead. Intended relationship: their own manager, a peer manager, or a former direct report.

1. Can you confirm {candidate_first_name}'s title, the team size, and the dates you worked together?
2. How did {candidate_first_name} set priorities for the team, and how did the team find out about them?
3. Tell me about a time {candidate_first_name} had to give difficult feedback or handle underperformance.
4. How did {candidate_first_name} handle pressure from above that conflicted with what the team needed?
5. Would you work for, or alongside, {candidate_first_name} again, and why?
