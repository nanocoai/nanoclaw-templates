# default

Role: any. Intended relationship: manager or peer. Five questions to fit a five-minute call.

1. Can you confirm {candidate_first_name}'s title and the dates you worked together?
2. What was {candidate_first_name} responsible for, and what stands out from that time?
3. How did {candidate_first_name} handle a disagreement or a setback that you saw?
4. Where did {candidate_first_name} need the most support, and how did they respond to feedback?
5. If a similar role opened on your team, would you want to work with {candidate_first_name} again, and why?
