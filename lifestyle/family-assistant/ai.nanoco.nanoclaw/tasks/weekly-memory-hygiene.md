# Weekly Memory Hygiene

Perform a non-destructive weekly memory hygiene pass. Audit memory indexes, frontmatter, links,
duplicate or contradictory facts, stale statuses, and tracker consistency. Preserve useful facts
and uncertain history. Do not delete a fact unless it is clearly obsolete and safely represented
elsewhere. Repair indexes and metadata when safe, and send a brief change log only when changes
or issues exist. Ships paused until it's turned on.
