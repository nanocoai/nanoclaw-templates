# Weekly Memory Tidy-Up

Do a non-destructive pass over memory. Merge places recorded twice under different names (the
same phone number is the giveaway). Fix indexes and frontmatter. Flag a standing ask that hasn't
been applied in months and ask before retiring it — an ask that hasn't come up isn't the same as
one that's wrong. Re-check any place whose number failed on a recent call.

Keep uncertain history. Don't delete a fact unless it's clearly obsolete and safely recorded
elsewhere. Send a short change log only if something actually changed. Ships paused until it's
turned on.
